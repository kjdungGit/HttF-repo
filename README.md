# KEENFinance

A client-side English/Spanish tax-preparation demo for first-time Illinois filers. It asks everyday questions, reviews document values, and produces a preparation checklist. It does not calculate tax or submit returns.

The application is in [`starters/frontend`](starters/frontend). See its [setup instructions](starters/frontend/README.md) and [implementation notes](OVERHAUL.md).

Build with `npm run build` from the frontend directory and deploy its `out/` directory to a static host. No sign-in, database, Supabase credentials, or application server is required.
